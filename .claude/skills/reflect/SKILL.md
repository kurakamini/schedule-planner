# CLAUDE.md への知見反映

1. このセッションを振り返り、次を洗い出す
   - ユーザーから受けた修正・指摘(コード規約、進め方の好み)
   - 二度と踏みたくないハマりどころ(環境固有の罠、コマンドの正解)
   - 判明したプロジェクトの暗黙ルール
2. CLAUDE.md の適切なセクション(迷ったら「知見メモ」)に 1 項目 1 行で追記する。長文化させない
3. 一時的な事情(今回だけの都合)は書かない。恒久的に役立つルールだけ
4. プロジェクト固有でなく全プロジェクトに効く知見なら、~/.claude/CLAUDE.md への追記を提案する
5. 追記内容をユーザーに見せて承認を得る
