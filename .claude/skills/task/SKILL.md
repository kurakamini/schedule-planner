# タスク実行

引数(任意): 実行するタスク名。省略時は未完了の先頭タスク。

1. docs/spec/tasks.md を読み、対象タスクを決める。requirements.md / design.md の該当箇所も確認する
2. 実装する。設計から外れる必要が出たら、勝手に進めず理由と代案を報告して判断を仰ぐ
3. テストを書き、実行して通す。テスト基盤が未整備なら、先に最小限のセットアップを行う
4. 完了したら tasks.md のチェックボックスを付け、変更の概要を報告する
5. 意味のある単位でコミットを提案する(勝手にコミットしない)
