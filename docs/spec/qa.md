## 人間が確認する項目

運用・環境に依存し、自動テストでは担保できないもの。実機・実運用で確認する。

- [ ] **通知は出ない**。時間が来ても鳴らないので、自分で画面を見に行く運用でよいか(スコープ外と割り切れているか)
- [ ] **朝 4 時をまたぐと今夜のプランがリセットされる**(夜境界)。それより前に就寝する前提で運用しているか。夜更かしで 4 時を越えると実行中プランが消える
- [ ] **PC がスリープすると開発サーバが止まる**。帰宅後に使うなら、使う時間帯に PC がスリープしない電源設定にしてあるか
- [ ] **ブラウザの「閲覧データ削除」でデータが消える**。Chrome の Cookie/サイトデータ削除でルーチン・設定ごと初期化される点を理解しているか
- [ ] **PC の IP が変わるとデータが見えなくなる**(localStorage はオリジン単位)。DHCP 予約で IP を固定したか
- [ ] 実機で、設定した**就寝時刻ちょうどに全タスクが収まる配分**になっているか(計算は端末の時計に従う)
- [ ] 同一端末で**複数タブを同時に開いて別々に編集**すると、後から保存した方で上書きされる(同時編集は非対応)。通常は 1 タブで使う
